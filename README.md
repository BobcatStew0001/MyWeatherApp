# 🌦️ Weather App (.NET)

A weather application built with **C# and .NET** that retrieves real-time weather data using the OpenWeather API. This project demonstrates API integration, clean architecture, and modern .NET development practices.

---

## 🚀 Features

- 🌍 Search weather by city zip-code
- 📍 Location-based weather (if implemented)
- 🌡️ Displays temperature, humidity, current conditions,  hourly forecast, 16 day forecast and weather maps
- 🔄 Real-time data from OpenWeather API
- 😂 Displays random/funny jokes & quotes
- 🧱 Built entirely with C# and .NET
- 🧼 Clean, maintainable code structure

---

## 🛠️ Tech Stack

- **Language:** C#
- **Framework:** .NET (ASP.NET Core / .NET 6+)
- **API:** OpenWeather API
- **Tools:** JetBrains Rider, Git, GitHub
